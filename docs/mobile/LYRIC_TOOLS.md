# 移动端在线歌词操作

2026-10-11，接续 [LYRIC_CACHE.md](LYRIC_CACHE.md)。播放器中的「歌词」现在为网易云／QQ 在线歌曲
提供文件导入、在线匹配、来源切换和恢复原始歌词。操作不替换队列、不重新启动音频。

## 复用和边界

- 直接复用原 `OnlineLyricMatchModal`、匹配查询和排序、QQ QRC／网易云歌词解析与预览。
  匹配编排抽到 `useOnlineLyricMatch`，新增可选原生存储与时钟；桌面调用默认仍用原存储和全局时钟。
  移动窗口使用上下排列，宽 iPad 继续左右排列；触摸区域、安全区和内部滚动只在移动包装层调整。
- 导入与来源状态转换提取为 `onlineLyricEdits`，原桌面控制器也调用它，字段和优先级保持一致。
  复用原文件读取器处理 UTF-8／UTF-16／GBK 和 KRC，原 ParserFactory／Worker 解析 LRC、VTT、TTML、
  QRC、YRC、KRC、TXT、FIA／JSON。导入格式清单与原文件弹窗共用；输入和解压后文本限制 2 MB。
  空歌词、超限、解析失败或保存错误会显示错误，不用空实现代替导入成功。
- 导入保留之前的在线匹配，重新匹配也保留导入文件，可反复切换。恢复操作确认后先读取歌曲所属平台，
  再清除这首歌的手动选择；网络失败保留原选择。普通缓存与替代来源分开保存，避免替代歌词污染原始来源。
- 编辑时暂停该歌曲的自动匹配，关闭后先显示保存的选择；这项暂停绑定歌曲身份，不抑制下一首的正常匹配。
  后续开发源码已允许编辑期间只读加载歌词，避免过早打开工具后校准预览一直空白；只读路径不自动写缓存。
  关闭、切歌、退出或缓存令牌失效后，迟到响应不能继续写入或覆盖新界面。保存失败留在弹窗内，允许重试。
- 对应原 `onlineLyrics` 面板功能，移动端提供触摸入口；没有新增全局设置或重复命令。
  本阶段不新增 npm、SPM 或运行库，不修改原歌词动效参数、音频处理、服务白名单或服务器配置。

移动匹配入口目前提供网易云和 QQ，与当前优先音源一致。后续开发源码已接入本地／在线单曲偏移和全局校准，
见 [LYRIC_TIMING.md](LYRIC_TIMING.md)，尚未安装到个人 iPhone。
AMLL／酷狗匹配、分词编辑、导出与批量工具、本地歌曲完整来源管理等仍待移植，
不能把这个入口称为原桌面全部歌词工具已完成。

## 验证

本机证据在 `.mobile-test-results/lyric-tools-*`，测试响应为合成样本，不等于真实平台 App 端到端验收。

- `lyric-tools-final-sync.log`：TypeScript、136 项逻辑／24 文件、前端构建和 Capacitor 同步 PASS。
  文件解码和选择状态使用实际原解析代码；Node 单测把 Worker 传输替换为直接调用同一个 parserCore。
  真正的浏览器 Worker 在下述 WebKit 用例中执行。
- `lyric-tools-final-ui.log`：15 项 PASS，39.8 秒；手机、宽 iPad、窄 iPad。覆盖导入、来源来回切换、
  QQ 原 QRC 解密与预览、写入失败重试、恢复原始来源、关闭／切歌后迟到结果、缓存／登录／队列回归。
  420px 高度检查保存按钮可达，不能替代系统键盘真机验收。三种匹配界面截图已人工检查。
- `lyric-tools-device.log`／`.xcresult`：iPhone XS Max／iOS18.7.10，15 项 PASS，11.256 秒。
  包括原生完整歌词缓存、选择优先级、清理取消、离线跨平台双解码队列、原本地／在线解析及衔接。
  这是原生专项；手机系统文件选择器与新匹配界面的手动操作尚未执行。
- `lyric-tools-device-identity.json` 核对 QA 宿主、插件、签名、entitlement 和 xctestrun 摘要；
  仅运行核对过的 `test-without-building`，测试后 QA 已卸载。
- 首次类型检查发现提取 hook 后缺少 setter 导出，已补齐；首次 Node 用例缺少 Worker，已将传输替换为
  原 parserCore 直接调用。界面用例两次分别误用来源标签、把合法的 `onlineOverrideLyrics: null` 当成
  迟到匹配，均按实际语义修正后重新运行。失败日志保留，没有改产品语义来迎合错误断言。

**NOT_RUN**：真实账号 App 在线匹配、真实文件选择器导入、平台权限／云盘矩阵、30 分钟锁屏跨曲、
实体 iPad、耳机／蓝牙、歌词视觉误差和持续性能。本阶段不改变完整移植仍在进行中的状态。
