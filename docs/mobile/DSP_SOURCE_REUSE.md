# 原版音效的 DSP 源码复用提议

状态：用户于2026-10-10明确批准“复用这几段 DSP 源码”；许可范围为下述固定版本的过采样、波形整形和压缩器运算。

目标：保持原版4倍过采样饱和与动态压缩的行为。原项目用 Web Audio 节点；
iOS 后台原生播放器不能依赖 WebView 中的 AudioContext 持续运行。

推荐从 WebKit 的 UpSampler、DownSampler、WaveShaperDSPKernel、
DynamicsCompressorKernel 中仅移植所需的 DSP 运算，适配为原生处理模块。
不引入 WebKit/WTF 库，也不新增 npm、SPM 或动态运行库。

- 上游：https://github.com/WebKit/WebKit
- 固定提交：9c50e091cb1b47fddb7afa7ffec7f9f22c0ee38b（2026-10-10）。
- 原始参考实现及压缩器头文件共41,350字节；移植后的二进制增量须实测，不能按源码大小推算。
- 许可证：文件内BSD两条款／三条款式许可，与AGPL项目兼容；保留完整版权、条件及免责声明，随源码和App分发。
- 维护：来源为持续维护的WebKit主线；抽出的适配代码由本项目维护，不自动跟随上游更新。
- 安全：不新增网络、账号、文件或设备权限；检查缓冲边界、非有限样本、参数范围和渲染线程分配。
  上游来源及许可证不能替代对移植代码的审查或安全验证。
- 验证：使用原项目曲线生成函数及WebKit OfflineAudioContext作独立数值参考；
  覆盖采样率、开关、过采样延迟、动态包络、声道链接、快速参数更新及实际原生tap。

备选：使用Apple系统DynamicsProcessor和Distortion等效果器。集成更短，
但曲线、自动增益、过采样和时间包络不同，无法保证原版预设音色一致，因此不推荐替换。
完全重写等价DSP仍需承担相同验证与维护成本，缺乏复用的经济性。

截止滤波、低位深、抖晃、声场及噪声继续移植项目已有参数与数学逻辑，
FFT／滤波使用已在工程中的Accelerate，不以此批准为前提。
