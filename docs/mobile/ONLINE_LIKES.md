# 在线歌曲收藏移植

2026-10-12。移植原版在线歌曲喜欢状态与现有写入能力，无新增依赖。个人 App、服务器和真实账户收藏均未修改。

## 功能与原版边界

- 曲库／搜索／播放队列的歌曲菜单、播放器「更多播放选项」共用同一触摸入口；保持已接受的全屏画布与控制器交互。
- 歌曲归属由 `sourceRef` 决定。使用 Omni 的登录检查、`getProviderLikedSongIds`、`canLikeSong` 和 `likeSong`，没有复制平台请求、建立另一份 Cookie 或改变播放状态。
- 网易云沿原版能力提供「喜欢这首歌／取消喜欢」。QQ 原版 provider 的 `mutations` 为 `false`，因此只显示已喜欢／未喜欢，不虚构 QQ 写入 API。本地收藏继续走原本地歌单逻辑。
- 网关 `/mobile/health` 的可选 `songLikeProviders` 仅在启用网易云时宣告 `netease`。客户端还需通过 Omni 能力检查；旧网关不返回此字段时只读，协议号仍为 1。
- 新网关只增开固定 `/like` 路由，要求有效正整数歌曲 ID 和显式 `like=true/false`。认证、平台启停、目标白名单、禁止重定向、凭据日志规则保持；网关 Authorization 不转发上游。

## 并发、会话与失败

- 面板打开后先确认所属平台登录，再读取完整喜欢 ID 列表。失败或未登录时不显示虚假的「未喜欢」；读取不写账号快照，不持久化另一份账号状态。
- 每次写入使用从已确认状态计算的明确布尔值，等待成功才更新爱心。同一平台写入在本次 App 生命周期内串行；快速点按不重复提交。
- 关闭面板不会把已经发出的写入当成未发生。重开面板等待这次操作结束，再读取服务器状态；错误或超时不自动重试、不直接反转，必须先重读。
- 会话代次在取消、退出或凭据替换时失效。Omni 的可选 guard 检查请求前及结果提交前，防止旧会话更新喜欢 ID／KuGou 行号缓存；默认桌面调用不需要此参数。
- 关闭、切到其他歌曲或进入后台使读取失效。QQ 逐页检查 guard，不再发出后续页；已在途的单个网络请求仍受现有原生超时／取消控制。回前台重新读取。
- 网易云适配器现在要求收藏响应 `code=200`；原先会把 HTTP 成功但业务失败的响应当作成功。`/like` 与 `/likelist` 加入已有时间戳规则，避免写入和随后读取命中旧 GET 缓存。
- QQ 无有效 `songs` 数组、分页提前停住或达到原 10,000 条上限但未读完时明确失败。有限的部分列表不能证明某首歌没有被收藏。没有扩展到无限分页。
- 界面仅显示固定本地化错误，不显示上游正文、请求地址或凭据。中／英／印尼文同步；原桌面 `playback-like` 命令与能力入口保持，没有新增设置或外观配置字段。
