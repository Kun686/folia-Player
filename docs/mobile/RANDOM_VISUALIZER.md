## 实现与行为

`src/mobile/PlayerPanel.tsx` 直接调用原 `useRandomVisualizerMode`，使用已有 store、
模式注册表及 `getPlaybackSongKey`；没有另写随机算法。播放器折叠后仍挂载，
因此回到曲库不丢失已观察的歌曲身份。QQ／网易云的同名数字 ID 按来源区分。

沿用原行为：首次恢复、开启开关、同曲进度／标题更新、旋转和重开面板不会重新随机；
换到不同歌曲才从注册表选取不同于当前的动画。手动选择保持到下一首，关闭后不再随机。
`VisualSettings` 增加已有样式的触摸复选框，复用原「每首歌随机歌词动画」翻译与 action。

原视觉配置类型、导出、短码、快照及应用逻辑已有该字段，但共享同步解析器遗漏了它，
导致配置导入显示成功却丢失开关。本次仅为 `randomVisualizerModePerSong` 增加严格布尔解析：
保留 `true`／`false`，忽略缺失及非法类型。同步协议版本与后端保持原样；桌面导入也受益。

WebView 挂起时不执行视觉随机或渲染；恢复后由收到的当前歌曲身份驱动原 hook。
本批受控测试覆盖折叠与重新加载，没有证明系统挂起／恢复的真机行为。
