保留原来的预览、匹配评分和解析规则。完整移植仍为 **IN_PROGRESS**。

## 实现与复用

- 原弹窗增加可注入的请求与保存接口；原桌面服务仍为默认实现。选择补丁、规范化歌曲字段和
  原有界面逻辑提取为共享模块，原 Dexie 实体分配流程保留。没有新增依赖或自研歌词解析器。
- 移动入口通过 Omni 查询网易云／QQ，再用原解析链预览和保存。没有把只选歌词的较窄弹窗当作
  完整匹配流程。手机与窄 iPad 保留三个开关、结果列表和预览，按窗口宽度滚动布局。
- 原生保存导入时的歌曲信息与匹配覆盖层；标题、歌手、专辑、封面选择和歌词在同一份记录中
  原子提交。原音频、导入歌词与内嵌歌词保持独立；恢复导入信息不销毁之前保存的匹配歌词。
- 每首歌曲沿用可撤销编辑令牌，异步校验后再次核对歌曲存在、任务取消和令牌。
  成功保存轮换令牌，过期／并发写入被拒绝；白名单校验使用原歌词文档验证器。
  匹配文档最多 3,000,000 UTF-8 字节，合并歌词记录最多 37,000,000 字节。
- 更新当前歌曲、重复队列项或已移出队列的当前歌曲信息时，保留解码器、播放位置和暂停状态。
  原生后台歌词规划与前台共用来源选择，保存后使旧规划失效；曲库通过事件刷新。
- 匹配封面复用已有缓存，封面 URL 版本参与缓存身份；离线可用，失败回退内嵌封面。
  封面预取失败只报告部分失败，不把已经提交的匹配信息报成保存失败。
- 关闭弹窗、切换搜索和重复点击有迟到结果保护；移动 QQ 搜索失败不再被 provider 吞掉并
  显示为无结果，原桌面空结果回退行为保留。错误可见后可以重试。

## 边界与回退

**NOT_IMPLEMENTED**：移动端本地歌手／专辑实体拆分合并、完整多标签采集、全部桌面编辑工具、
完整 Automix。Partita 长词裁切由后续源码适配，见 [PARTITA_FIT.md](PARTITA_FIT.md)；
本匹配阶段没有修改原版动画参数。
移动原生存储没有拆分实体，因此不虚构桌面 assignment ID。

**NOT_RUN**：本阶段实体 iPhone／iPad、三平台长时间锁屏、耳机／蓝牙、网络切换、
≤150ms 歌词显示误差、持续温升和内存。网易云／QQ 真实账户 App 在线链路仍待验收；酷狗按后续范围延后。
本地导入、播放和已保存的匹配信息不依赖网关；在线查询当前仍依赖音乐 API 网关，
它与可选的数据同步服务不同。本轮没有部署域名或修改服务器。

回退源码提交可撤销新入口和覆盖层读取。旧版本忽略 `matchJSON`，仍可读取原音频与兼容歌词；
旧版再次编辑可能丢弃未知字段，而且不会遵从新增在线来源选择，需要保留 App 数据备份。
可读取旧格式不表示跨版本编辑无损。构建身份仍以对应版本的 `BUILD_RECORD.json` 为准。
