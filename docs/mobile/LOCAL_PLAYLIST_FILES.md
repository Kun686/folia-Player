# 移动 M3U 歌单文件

2026-10-12，接入「本地音乐 → 歌单 → 导入歌单」和歌单内「导出 M3U8」。
使用原版路径匹配与格式规则；M3U 是歌曲引用清单，不包含或下载音频。

## 复用与行为

- 原 `localPlaylistFileService` 的纯格式、路径匹配分别移到 `localPlaylistM3u` 和 `localPlaylistM3uPaths`。
  原桌面 import/download API 保留；移动端不引入桌面数据库适配器。
- 按原始文件名匹配已导入的原生歌曲，复用 Windows／file URL／相对路径归一化、去重和原顺序。
  同名多个候选与缺失歌曲分别报告并跳过；远程 URL 不下载、不转发。移动目录不含原文件夹树，
  不声称保留桌面文件夹路径层级；重名文件不会凭标题猜测。
- 原版序列化补充两个格式边界：以 `#` 开头的文件名前加 `./`，路径内换行编码，
  避免导出被当成指令／注释或多条引用；原普通目录导出规则不变。
- 文件选择器不设置 accept 扩展名过滤，避免 iOS 不认识文件 UTI 时置灰；选中后校验 M3U／M3U8、
  UTF-8 编码、2,000,000 字节和 10,000 条引用上限。空清单和完全不匹配清单不能创建歌单。
  可以预览匹配数量并编辑名称；保存时在既有 IndexedDB 事务内重新读取完整原生目录和匹配，
  不把预览时的旧歌曲直接写入。期间歌曲删除会重新报告未匹配，全部消失则不创建空歌单。
- 导入写入失败保留文本／名称，可重试；成功后不重复提交。取消文件选择不丢弃现有预览。
- 导出再次读取最新歌单与目录，保留当前顺序、名称、显示元数据和原始文件名。
  旧导入若没有原文件名，会使用原生 ID，界面提示仅能在本机匹配。重复文件名仍可能在回导时被跳过，
  这不是包含全部音频和身份信息的备份格式。
- `sharePlaylistFile` 使用独立 `.m3u8` allowlist、2 MB UTF-8 上限和路径／控制字符校验，
  内部复用 `LyricFileShare` 的唯一分享占用、iPad 弹出定位、受保护临时文件和分享完成后的清理。
  歌词／ZIP 接口的 allowlist 保留，不能借该接口导出任意文件。完成与取消分别显示，失败允许重试。
- 文件名复用 `sanitizeDownloadFileName`，按 Unicode 码点限定长度，保证多字节名称不超过原生文件名限制。

没有新增生产依赖，没有修改音频／歌词存储或服务器；沿用已接受的播放器样式。

## 证据与边界

- TypeScript 与 28 项相关逻辑通过：原桌面歌单／M3U、移动文件编码／大小／名称、事务导入、
  删除后重新匹配、失败回滚、导出最新顺序／旧文件提示及回导。
- 27 项 WebKit 通过：三个视口的 M3U 预览／导入／重启、导出回导、分享失败／取消／重试、
  写入失败保留／重试，另含上一版歌单／收藏回归。使用真实 File API 和 IndexedDB；原生接口为 fixture。
- 3 项 iPadOS26.5 原生 XCTest 通过：M3U UTF-8／allowlist／路径／大小校验，原歌词与 ZIP 拒绝非法输入。
  `.mobile-test-results/m3u-native.xcresult`；此项不证明系统文件选择或分享交互。
- M3U／歌词分享 WebKit 回归 21 项通过，与上述 27 项中 15 项重叠，合计 33 项独立用例。
- 最终 mobile.26 签名 iPad 模拟器实际完成系统分享「存储到文件」、选中 M3U8、匹配 1 首、导入，
  终止重启后歌单仍在。样本为历史合成音频，因缺原文件名使用已提示的本机 ID 回导；原文件名分支是自动测试证据。
  实际保存文件 100 字节，UTF-8／CRLF 与歌单一致；临时分享文件已清理，保存的用户文件保留。
- mobile.26 的前端同步、模拟器／iPhone Release 签名构建、源码／资源／IPA 核验及准确源码 CI 通过，
  已于 2026-10-12 原位安装个人 iPhone XS Max / iOS18.7.10、启动并回读 build26。
  本版手机新功能与在线回归仍为 NOT_RUN；证据与安装包摘要见 [VALIDATION.md](VALIDATION.md)。

2 MB／10,000 条以上文件、GBK 等旧编码、大曲库性能、物理 iPad 尚未验收。
完整文件夹管理、稳定曲库实体编辑、完整 Automix 和其余原桌面工具仍未交付。

## 回退

原位安装保留的 mobile.25，不卸载个人 App。没有歌单数据库版本迁移；已创建歌单可继续使用，
旧包不显示新增的 M3U 入口。导出到「文件」的 M3U 属于用户文件，不随分享临时目录清理。
