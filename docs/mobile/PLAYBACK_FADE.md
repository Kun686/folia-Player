## 原版复用与行为

- 将原 playbackFade.ts 的控制器抽到 playbackFadeController.ts，Web 公共接口与原测试保持兼容。
  Web 与原生 JavaScriptCore 运行同一调度逻辑：200ms 线性淡出／淡入、15ms 暂停宽限、150ms 尾音排空、
  30ms 归一恢复；代次令牌防止旧回调暂停新播放。重复暂停不重新计时，快速恢复从当前增益反向淡入。
- 原生只增加计时器桥接和立体声线性增益，复用现有 AudioEffectUnit、解码器与标准库。
  增益在双声道、Automix 和分轨混合及效果之后、频谱采样之前；用户音量／静音与 ReplayGain、转场曲线独立。
  音频回调不分配缓冲区，不等待控制线程锁；按输出采样率逐帧插值，保持左右声道相位与幅度关系。
- 暂停意图立即反映到 UI 与锁屏状态，音频继续完成淡出后才暂停解码器及整体效果链。
  Automix 双声道也到淡出完成后才清理。继续播放在首个音频块之前置零，实际解码开始后运行原淡入。
- 切歌和拖动会处理待执行暂停；停止、网络失败、账号失效和系统中断会取消旧回调。
  耳机／蓝牙输出断开仍立即停声。旧 AVQueuePlayer 回退没有此立体声增益，按原无音频图路径立即暂停。
- 播放器「更多播放选项」使用原「暂停/播放淡入淡出」文案、store 与 action；
  原命令面板已经注册同一 action。原生保存设置并负责恢复，旧文档与原版一致默认开启，非法写入不部分生效。
  播放器全屏布局、控制器质感、歌词动画算法和音效参数未调整。
