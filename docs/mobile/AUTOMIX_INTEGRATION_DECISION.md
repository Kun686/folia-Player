# Automix 原模型接入评估

2026-10-11。状态：**PENDING_APPROVAL**。此文件是可审阅的接入方案，不是已接入或已验收声明。
现有授权只覆盖官方 Apple ORT 1.30.0 独立验证。按用户「新增生产依赖前……未经允许不要安装」规则，
将该库加入 Folia App 工程需要批准；已批准的独立验证无需再次申请。

## 建议与复用

建议批准固定 ORT 1.30.0 的 App 工程接入开发，**先在独立 Folia QA 包完成联合验证**。
播放／动画争用和真实音乐门槛尚未通过，本次接入开发不直接更新个人 mobile.20，也不默认启用模型。
不改用户已接受的全屏、半透明控制器和空白点按交互。

| 复用能力 | 接入工作 |
|---|---|
| `shared/modelManifest.json`、原模型与下载状态／设置 | iOS 下载、校验、原子保存和取消；模型按需准备，不塞入基础 App，不携带桌面 Python |
| 原 `melSpectrogram`／`beatsFromLogits`／`analyseTrack` | 通过现有 JavaScriptCore 分析桥注入原生推理，保留无模型分支的原语义 |
| 原 `htdemucs_runner.py` 拼接规则与本次 C++ 对照 | 薄 Objective-C++ 调用边界、逐段取消、输入／输出检查、任务结束释放 |
| `NativeTrackProfiles`、`NativeProfileCache`、`NativeProfileIdentity` | 接入模型能力／版本缓存身份，沿用队列意图和账户取消，旧 gridless 缓存不冒充新模型结果 |
| `NativeMediaCache`、`PlaybackMediaCache`、本地导入 | 分轨只读本地或完整缓存；不为分轨额外下载音频，不把前缀当完整文件 |
| 原 `stems.ts`、`stemGesture.ts` | 保留 30 秒窗口、最多 4 个缓存窗口、峰值缩放 16 位 PCM、other 相减及人声退出规则 |
| `NativeTransitionPlanner`、`NativeMasterTransition`、`TransitionDeckProcessor` | 执行原分轨手势与曲线，连接现有音频时钟、取消和动画 cue |

已有 AVFoundation／Accelerate／JavaScriptCore 不能直接执行这两个 ONNX 模型，现有 Node 运行库不能用于 iOS。
新增依赖的作用仅为执行原模型；自研部分只承担平台 I/O、线程、生命周期与播放适配，不另写推理或过渡算法。

  63,965,603 字节，已下载校验，不需要再次下载同一产物。该哈希是本地记录，不冒充上游签名。

  2026-10-11 官方来源与通告查询记录见 [运行库评估](AUTOMIX_RUNTIME_130.md)。

## 实测约束与接入门槛

独立 [完整窗口](AUTOMIX_WINDOW.md) 已运行：XS Max 约 33.1 秒／30 秒音频，峰值约 1.08 GiB。
它只能说明推理可运行，不能证明与真实播放器及 WKWebView 同时运行可接受。
vocals 浮点 relativeL2 1.1004219e-4 未通过原 1e-4 诊断门槛；16 位存储最大差 1 单位，
无明显人声样本的退出判断相同。保留失败，真实人声样本与手势输出对照是接入验收的必需项。

1. **依赖与桥接**：在独立 QA 身份构建真实 Folia 播放器；固定原模型／二进制校验，错误模型不加载。
   Session、推理和分析串行，禁止与另一个模型并发；音频渲染线程与主线程不运行推理。
2. **原行为对齐**：真实音乐的拍点、人声退出、30 秒接缝、16 位缓存和四轨混音对照；
   重放原曲线与手势。阈值失败必须说明原因和影响，不能静默放宽。
3. **队列与资源**：提前准备当前／临近歌曲，旧意图不可写回；跳歌、拖动、退出账号、
   删除来源、内存警告和热状态变化取消无用任务。公开 `SetTerminate()` 后等待工作线程结束再销毁会话。
   收不到足够提前量时沿原版主混音回退，不缩短原窗口、不拖住正常播放。
4. **联合真机验证**：现有 AudioStreaming 输出与原歌词动画同时运行，测总内存、渲染连续性、
   主线程卡顿、取消响应、后台跨曲和长时间温升。出现系统杀进程、音频断续或持续增长时停止启用模型。
   单探针的 0 次内存警告不能替代此项；物理 iPad 仍需单独验收。
5. **个人安装**：上述门槛满足后，再给出可安装候选、准确源码／签名／体积和实测记录；
   本次接入授权不包含直接替换个人 App。永不卸载个人 App，保留登录、曲库和可回退包。

## 替代方案与回退

| 方案 | 成本与限制 | 判断 |
|---|---|---|
| 固定官方 1.30.0，先独立 Folia QA 接入 | 运行库适配成本最低；内存和争用待测，沿原模型行为 | 推荐下一步 |
| 继续现有无模型主混音 | 无新增包体或推理资源；缺分轨和模型拍点 | 可作为原版回退，不能算完整 Automix |
| 等官方较新 Apple 包 | 暂不改工程；等待时间及兼容性未知 | 可暂缓接入，不承诺发布日期 |
| 自编 ORT／Core ML／改模型 | 新工具链与数值、许可、跨架构维护成本 | 当前不推荐，不在本次授权范围 |
| 服务器推理 | 运维、网络、隐私和离线行为改变 | 不作为忠实移动移植的默认方案 |

回退按独立提交撤销 App 链接／桥接，原始模型与媒体保持不变；QA 可独立卸载。
个人 mobile.20 不参与本轮试验。关闭／不可用时遵循原能力判定，不显示“完整 Automix 已启用”的虚假状态。
