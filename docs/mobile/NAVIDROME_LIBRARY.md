# Navidrome 移动设置与曲库浏览

本批把已有 Navidrome 原生连接、播放、歌词和封面接到移动触摸入口。个人 App 保持 mobile.28，未操作真实账户、服务器或物理设备。
完整移植仍未完成；Navidrome 写入功能及真实服务验收另行完成。

## 复用与行为

- 设置页复用现有移动面板，地址允许 HTTPS 子路径。密码只写入既有 Keychain 接口，不回填到网页、不进入 localStorage 或视觉设置备份。
  留空保留密码；更换服务器或用户名须重新输入。清除密码同时停用。失败保留草稿，连接测试可取消。
- 复用原 `navidromeReadApi`、首页模型、专辑分页上限和歌曲转换。将原首页／集合读取提取为可注入连接的共享函数，桌面端默认行为保留。
- 新入口提供专辑、最近加入、最近播放、艺术家、歌单、随机音乐、收藏与歌曲／专辑／艺术家搜索。
  专辑最多 500×20 页；搜索保留原请求默认的 5 位艺术家、10 张专辑、20 首歌曲，本批没有增加搜索续页。
- 专辑／歌单播放设置整组队列；搜索播放复用原“已有则选中、否则追加单曲”的行为。加入队列复用原默认位置与去重规则。
  歌曲身份使用服务器账号 scope 和原 mediaId，播放交给已有原生队列，原全屏、歌词动画与音效算法不变。
- 账号变更立即废弃旧页面工作；导航取消旧请求，迟到响应不覆盖新页面。待加队列操作在异步读取前后核对账号。
  多专辑艺术家按两路展开，复用原生连接的有界请求队列。
- 集合封面复用原生封面下载、ImageIO 缩图、磁盘预算、撤销与重定向保护。可见行最多同时发起两路读取。
  WebView 只取得图片 data URI；原生按 scope 校验并签名，音乐网关认证头和平台 Cookie 不参与。
  原歌曲封面缓存键与文件格式保持不变，集合图片使用独立身份键。
- 未新增依赖；没有改动个人构建记录、原主题默认值或原音频处理。

新测试验证了 80 张专辑展开、账号变化时的队列取消、过期响应丢弃、只写密码、缓存撤销以及签名重定向目标零请求。
真实 Capacitor 调用进一步验证注册的方法仅返回可解码图片，并拒绝无效身份／旧账号；原有 Keychain 与共享连接桥接用例同轮通过。

测试过程保留失败记录：首次新增单测将原队列适配器的嵌套元数据误当成扁平结构，修正测试契约后通过；类型检查补齐样本的 Subsonic 必需字段。
界面首轮误用了“保存”／“搜索”按钮名称，按实际“保存连接”／“搜索歌曲”修正；扩大旋转回归的旧选择器匹配到四个下拉框，改为按主题标签定位。
测试还发现搜索卡片切换时混用 `flex` 与 `flexGrow`，已改成明确的独立属性，最终回归无该警告。
原有 QQ 样本的 `DecompressionStream warning (ignored)` 仍由解析器记录，相关歌词与搜索测试通过。
