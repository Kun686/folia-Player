# 原版批量歌词导出移植

2026-10-11，mobile.15 源码 `1fc4c216b5ab713459f6c2c19bb51010ae57dd01`。
复用 `LyricExportSurfaceView`、原缓存选择、歌词调整、命名、FIA／LRC 序列化及已安装的 fflate。
Swift 只提供缓存枚举、读取和 ZIP 系统分享，没有新依赖或播放、音效、动画参数变更。

## 行为与边界

- 设置可直接进入“批量导出歌词”，无需当前歌曲；原单曲导出弹窗也保留原版批量入口。
- 原版导出范围：已缓存在线歌词，以及本地歌曲当前选用的在线匹配歌词。
  本地内嵌／导入来源不进入批量范围，仍可单曲导出；这是原版筛选规则。
- 保留两种格式、LRC 翻译／罗马音开关、可选联网补全命名、重复文件名处理及 manifest 跳过原因。
  联网补全通过原 Omni 层；没有另写 provider 请求。
- FIA 保存原歌词、分词和单曲校准；使用移动端完整平台歌曲键，QQ／网易云相同 ID 不串用校准。
  全局设备校准、视觉过滤和歌词动画不写入导出文件。
- 新写入的在线缓存附带经白名单清理的歌曲身份及显示元数据，不保存 Cookie、音频或封面签名地址。
  旧缓存没有可还原的歌曲身份时，仅从当前队列查找经过完整身份校验的匹配；无法匹配则保留原歌词，
  在 manifest 和完成提示标注无法恢复歌曲分词／校准。导出不会擅自迁移或覆盖旧缓存。
- 缓存读取或分词存储出错会明确失败。关闭／取消后不会迟到分享；快速双击只启动一次。
  清除在线缓存或退出账号撤销导出 token，旧读取和提交分享不能继续。
- ZIP 上限 16,000,000 字节，超过后提示按范围／格式分开导出。复用系统分享的临时目录清理及 iPad 锚点；
  原生拒绝非法路径、扩展名、base64、过大数据和非 ZIP 文件头。用户取消不记为导出成功。
